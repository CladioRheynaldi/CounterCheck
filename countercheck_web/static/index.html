Metric definitions and limits

WER = (S + D + I) / reference words. CER uses reference characters. RTF = processing seconds / audio seconds. Throughput = audio seconds / processing seconds.

These are small pilot results, not full café validation. Controlled overlapping voices and simulated bandwidth are not physically recorded café noise. Latency is measured separately.
